# 🏙️ 城市韧性评估方法论说明

> 📊 基于综合赋权法的城市多维度韧性评估体系

## 📖 项目简介

本项目是国家自然科学基金课题的子项目之一，旨在构建一套**科学、可量化**的城市韧性评估方法论体系。以**北京市**为研究案例，从多个维度对城市系统应对外部冲击和恢复能力进行综合评估。

## 🎯 核心目标

获取目标城市在特定时间（月度）的**综合韧性水平**，为城市风险管理与规划决策提供数据支撑。

## 🧩 评估框架

本体系围绕**四个核心维度**展开，每个维度包含两个外部性指标和一个预测性指标：

| 维度 | 外部性指标 | 预测性指标 |
|:---:|:---|:---|
| 🏗️ 基础设施 | 通信覆盖韧性、燃气承载韧性 | 设施服务韧性预测值 |
| 🚇 交通运输 | 轨道交通韧性、综合交通韧性 | 交通风险抵御韧性 |
| 🌿 生态环境 | 排水恢复韧性、排水抗冲击韧性 | 生态健康韧性 |
| 🏥 公共医疗 | 资源保障韧性、治理协同韧性 | 医疗服务韧性 |

## 🔬 方法论流程

```
数据采集 → 数据补齐 → 归一化 → 正向化 → 平滑处理
                                          ↓
              综合赋权法 ← 熵权法权重 + 平均权重
                  ↓
         专题韧性计算 → 总体城市韧性
```

### 核心方法

- **📈 熵权法 (Entropy Weight Method)**：基于信息论的客观赋权方法，让数据本身"说话"
- **🧠 概念神经网络**：用于预测性指标的计算，兼顾特征表达与动态更新
- **⚖️ 综合赋权法**：融合熵权法与平均权重，平衡数据客观性与指标均衡性
